# GPS - Gestión de proyecto de software
Las 4 responsabilidades de un gestor de proyecto son:

| Las 4 P's | Tipo              | ¿De que manera es responsable?                         |
| --------- | ----------------- | ------------------------------------------------------ |
| Personal  | ¿Quien?           | Definir con quien trabajar                             |
| Producto  | ¿Qué?             | Definir las características que debe tener el producto |
| Proceso   | ¿Cómo?            | Definir los procesos que se van a utilizar             |
| Proyecto  | ¿Cuándo y Cuanto? | Ejecutar todo el plan con exito                        |

1. ¿Un ingeniero de software puede ser gestor de proyecto?
Si.
2. ¿Un gestor de proyecto también es conocido como el especialista de la aplicación?
Si.

# Personal
- Debe conocer la cantidad de recursos, conocer al equipo, organizar y asignar roles, etc.
- Seguimiento y control de los integrantes del equipo.
- Motivar al equipo ¡Importante!

# Producto
- Definir y organizar las características de un producto. Las características son:

| Req. Funcionales         | Req. No funcionales |     |
| ------------------------ | ------------------- | --- |
| Req. Funcionales         | Req. No funcionales |     |
| Relacionados al producto | Aspectos de calidad |     |
| código                   | ..                  |     |

# Proceso 
- Definir los procesos, que van a utilizar: Metodología, herramientas, etc.

# Proyecto
- Responsable de la planificación, de ejecutar todo del plan y asegurarnos que el proyecto se cumpla con éxito.


3. ¿Qué pasa con el proyecto cuando el gestor se va?
Se lo reemplaza con otro, pero el nuevo gestor va a tener nuevas características y puede cambiar al equipo, puede hacer cualquier cosa, por eso es tan importante el gestor

# Características que debe tener un Gestor de proyectos
- Liderazgo
- Inteligencia
- Autodidacta
- Conocimiento Técnico
- Tolerancia a la presión
- Motivador
- Organizado
- Ético y honesto

# Características de un ingeniero de software para ser analista (Orientado a la comunicación con el cliente)

- Organizado
- Habilidad de negociación
- serenidad (foco encendido)
- Bueno tomando decisiones
- Motivador
> Todo lo anterior lo podemos reducir a una palabra: `LIDER`
> Algunos extras:
- Compromiso
- Paciencia
- Persuación
- Empatia
- Critico
- Logico
- Objetivo
- Imparcial
- etc...

4. ¿Cuál es el propósito de motivar?
- Aumentar la Productividad
- Aumentar la Calidad
- Transmitir Energía
- Fortalecer el trabajo en equipo
- Desarrollar el potencia de cada persona

4. ¿Que harían para motivar a los demás?
- Darle un Bono
- Mejor puesto
- Mejorar el ambiente de trabajo
- Mejorar el trato
